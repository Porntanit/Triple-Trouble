# Implementation notes

Inspected the cloned repository at commit `9a3633a` (`Merge GitHub README and local project`) before editing. The actual clone contained an existing Flask/Ollama app, even though the web preview of GitHub was stale. Work remains local; no commit, push or deployment was performed.

- `app.py`: preserved existing chat/document endpoints and PDF pipeline; added profile, compare, evaluation, export and health endpoints; integrated profile-aware prompts; added explicit reindexing, vector/message validation, a 0.25 retrieval cutoff, CSRF protections and a persistent random session key. Failed PDFs no longer reindex automatically on every page/chat request.

- `AGENTS.md`: replaced obsolete empty-repository descriptions with current layout and commands.

The original runtime dependencies and model names remain unchanged. No parent project `sources/` files were modified.

## Daily calorie tracking update

Added `calories.py` for per-profile settings, daily target snapshots, food entries, rating validation and totals. `/evaluation` now renders the manual calorie tracker; the previous experiment evaluation page moved to `/answer-evaluation` using `templates/answer_evaluation.html`. Updated navigation, comparison links, deletion cleanup, browser handlers and styles. The new endpoints are GET/PUT `/api/calories`, POST `/api/calories/entries`, and DELETE `/api/calories/entries/<id>`. Targets, logged food kcal and self-ratings are supplied by the user, not generated by AI.

## Connected photo diary and profile-derived targets (latest)

- Added `energy.py`: validated exact adult age, height, weight, explicit published equation coefficient and deterministic Mifflin–St Jeor × activity-factor maintenance estimate. `storage.py` migrates existing profile tables without deleting data. Profile saves synchronize today's and future default calorie targets; older date snapshots remain.
- Added `food_images.py`: image validation/resizing/EXIF removal, native macOS Vision classification/OCR, Gemma serving estimates, verified explicit kcal parsing from label text, temporary expiring scan drafts, owner-checked previews/photos, idempotent consumption confirmation and confirmed-photo gallery. Confirming inserts the calorie entry and photo together in one SQLite transaction; deleting the entry removes the photo.
- Added `static/images.js`, `templates/image_scanner.html`, `templates/food_collection.html`: shared scan → review → explicit confirmation flow in Nutrition chat and tracker, adjustable portions/grams and date, optional food names, and a collection containing only confirmed images.
- Updated `templates/profile.html`, `templates/evaluation.html`, shared navigation, `static/app.js` and styles. Removed the manual target form and visible/manual food-calorie entry form. Preserved rating/history/date behavior.
- Removed Compare/answer-evaluation UI routes and comparison/rating write endpoints at the user's request. Historical records and their session-scoped JSON export remain. Old templates are unserved reference files.
- `/documents` now shows confirmed meal photos; the preserved PDF source interface moved to `/knowledge`. PDF upload/download/reindex/delete and RAG remain functional.
- Updated runtime requirements with Pillow and pinned PyObjC framework wheels for Mac OCR/classification. `gemma3:1b` and `nomic-embed-text` remain the only required Ollama models. An optional extra vision-model download was stopped after verifying native macOS classification, and this task's unreferenced download artifacts were cleaned up.
